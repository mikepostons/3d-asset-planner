# Export hub and header cleanup

One Export button opens three large choices: reference package, model and complete
package. Complete uses the reference scope (whole scene) and terrain option and adds
a centred structural GLB and geometry report to the same ZIP. It includes saved, current Cleaner UV preparation. Unsaved preview changes must
first be saved in Cleaner. Missing/outdated preparation is warned about in Export.

Library is an accessible icon button; Save has a disk and orange unsaved/green saved
states, replacing the name-adjacent status. Help moved to the canvas footer. Updated
settings/package/export icons and renamed Model Cleaner header action to Cleaner
with a broom icon. Modal states disable the editor and shortcuts behind them.

72 tests pass and production build passes with existing bundle warning. Complete
package combines the existing tested GLB and reference exporters; browser verification
of the new combined download remains pending.
