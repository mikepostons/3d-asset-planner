# 17 September 2026 — Editable straight-wall openings

## Delivered

Added face activation and a conditional Openings toolbar menu with icon tiles for doors, windows, arched variants and circular windows. Dragging on the active plane produces a snapped outline; valid candidates commit as nested children under Component → Openings. Sidebar controls edit names, sizes, wall offsets and sill/base heights, and delete individual openings.

Added optional hollow walls with adjustable thickness (default 0.4 m), a simple floor slab and interior reveals. Solid parts receive shallow recesses instead. Geometry regenerates from contours rather than accumulated booleans; the existing roof remains separate. Selected openings show depth wireframes without forcing whole-scene X-ray. Face highlighting follows cut geometry.

Openings survive save/import/export, parent movement/rotation, duplication and uniform scaling. Ordinary wall resizing keeps opening sizes/offsets and rejects invalid fits. Keyboard deletion targets an active opening; the explicit Delete part button still removes the parent. Metadata is included in brief and manifest.

## Verification

All 38 automated tests pass; production build passes with the existing bundle-size warning. New tests exercise all five hollow cut shapes, adjacent wall preservation, finite geometry, solid recess backs, serialization, scaling, overlap/out-of-bounds rejection and reshaped footprint frames. Isolated browser checks confirmed face activation, shape menu, drawing a window, its nested hierarchy/settings, switching to hollow walls and undo/redo of that change. Later refinement adds the hollow checkbox to the menu and prevents highlight fill across cutouts. Full nine-view export comparison was not repeated.

## Constraints

Straight convex four-corner wall surfaces only. Curved walls/roofs, overlapping cuts, door panels, glass, frames and internal storeys are deferred. Arched shapes use segmented curves. The floor slab sits 0.12 m below the component base. Interior offset construction is validated; this remains a blockout tool rather than a watertight production-mesh or UV exporter. Subdivision preview still represents the underlying body and is not cut-aware topology.
