# Asset Designer documentation

Last reviewed: 17 September 2026. Application version: 0.1.0.

Asset Designer is a local 3D structural blockout editor. It creates consistent architectural references for artwork generation; it does not generate finished artwork or game-ready meshes.

## Reading order

- [Architecture](architecture.md): stack, source map, state, geometry, rendering and exports.
- [Data and persistence](data-and-persistence.md): scene format, SQLite, API, recovery and backups.
- [Feature status](feature-status.md): completed capabilities, constraints and future candidates.
- [Development workflow](development.md): setup, verification and documentation maintenance.
- [Devlogs](devlogs/README.md): dated development records and verification evidence.
- [User guide](../README.md): editing and saving workflows.
- [Original plan](../PLAN.md): historical design proposal, superseded where current documentation differs.

The feature register describes the current implementation. Devlogs record how it evolved. The original plan contains unimplemented proposals and must not be read as a completion checklist.
